# Data

These are the files from the Data tab of the Kaggle competition "The Procurement Desk"
(Data Sprint 2.0, license CC BY-SA 4.0). They are included unchanged so the results can be reproduced.

| File | Used for |
|---|---|
| `playbook/` | Acme's rules, read by `agent/playbook.py` (included) |
| `threads.csv` | the 2,000 threads; input for the final submission |
| `sample_threads.csv` | the 40 worked examples |
| `sample_answers.csv` | correct labels for the 40 worked examples |

If any CSV is missing, download it from the competition's Data tab and place it in this folder.
